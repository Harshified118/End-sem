# vibe-coding-ui Project Guidelines

## Stack & Libraries
- **Framework:** Next.js (App Router, Turbopack, TypeScript)
- **Styling:** Tailwind CSS v4
- **Animation:** motion (Framer Motion v12)
- **Components:** shadcn/ui base (src/components/ui/)
- **Linter & Guardrails:** impeccable design hook enabled
